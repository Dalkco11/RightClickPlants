## 🇺🇸 English

**Right Click Plants** is a client-side Minecraft mod that lets you harvest mature crops and automatically replant them — all with a single right-click.

### ✨ Features

- **Right-Click Harvest**: Right-click any mature crop to instantly harvest it.
- **Auto Replant**: The mod automatically replants the seed in the same spot.
- **Smart Timing**: If the seed drops and lands in your inventory, the mod will replant it within 5 seconds.
- **Server Compatible**: Works on any server — no server-side mod required.
- **Supported Crops**: Wheat, Carrots, Potatoes, Beetroot, Nether Wart, Cocoa Beans.

### 📥 Installation

1. Download and install [Fabric Loader](https://fabricmc.net/use/).
2. Download [Fabric API](https://modrinth.com/mod/fabric-api).
3. Download **Right Click Plants**.
4. Place all `.jar` files into your `mods` folder.

## 🇷🇺 Русский

**Right Click Plants** — клиентский мод для Minecraft, позволяющий собирать созревший урожай и автоматически пересаживать его — всё одним нажатием ПКМ.

### ✨ Особенности

- **Сбор по ПКМ**: Нажмите ПКМ на любое созревшее растение, чтобы мгновенно его собрать.
- **Авто-пересадка**: Мод автоматически пересаживает семя на то же место.
- **Умная задержка**: Если семя выпадает и попадает в инвентарь, мод пересадит его в течение 5 секунд.
- **Совместимость с серверами**: Работает на любом сервере — серверный мод не нужен.
- **Поддерживаемые растения**: Пшеница, Морковь, Картофель, Свёкла, Нетерровая бородавка, Какао-бобы.

### 📥 Установка

1. Скачайте и установите [Fabric Loader](https://fabricmc.net/use/).
2. Скачайте [Fabric API](https://modrinth.com/mod/fabric-api).
3. Скачайте **Right Click Plants**.
4. Поместите все `.jar` файлы в папку `mods`.
